# PawCare — Pet Grooming Center Frontend

A separate React + Vite frontend for the existing Spring Boot Pet Grooming Center REST API. The frontend is **not** inside `src/main/resources/static` and does not change your backend files.

## Requirements
- Node.js 18+ (Node 20+ recommended)
- Spring Boot backend running at `http://localhost:2273`
- Controller CORS configured to allow `http://localhost:5173` (if using `@CrossOrigin`, use `@CrossOrigin(origins = "http://localhost:5173")` on the controller or class)

## Run the frontend
Open a terminal in this `PetGroomingCenter-Frontend` directory and run:

```bash
npm install
npm run dev
```

Open the Vite URL shown in the terminal, normally `http://localhost:5173`.

## API calls used
- `GET    http://localhost:2273/centers/displayAll`
- `GET    http://localhost:2273/centers/displayBy/{id}`
- `POST   http://localhost:2273/centers/add`
- `PUT    http://localhost:2273/centers/update?id={id}`
- `DELETE http://localhost:2273/centers/delete/{id}`

Axios calls are centralized in `src/services/centerApi.js`; all page actions use `async/await` and display loading/error feedback.

## CORS
Since the frontend runs on port 5173 and backend on port 2273, they have different origins. The backend must allow the frontend origin. Example on the controller:

```java
@CrossOrigin(origins = "http://localhost:5173")
@RestController
@RequestMapping("/centers")
public class PetGroomingCenterController {
    // Existing controller methods remain unchanged
}
```

If you already added `@CrossOrigin`, verify that it allows `http://localhost:5173`. No CORS change is required if your existing annotation already allows this origin.

## Backend field names
The frontend sends `centerName`, `location`, `contact`, `servicecount`, and `open`, matching the Java entity property names in the supplied backend project. The ID is generated by the backend and is not entered on the Add form.

If the backend uses another URL/port, create a `.env` file based on `.env.example`, update `VITE_API_BASE_URL`, then restart Vite.
